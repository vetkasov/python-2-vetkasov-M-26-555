## Границы подтверждённого результата

- Совместимость с закрытыми тестами курса не подтверждена.
- Ветка main не переписывается; последовательная переделка находится в ver2.
- Имя репозитория python2-vetkasov-M-26-555 задано владельцем. Оно не совпадает
  с буквальным шаблоном project#2_<фамилия>_<группа>; имя дистрибутива соответствует
  разрешённому преподавателем project-2-<фамилия>-<группа>.
- JSON-файлы заменяются атомарно по отдельности. Общей транзакции между файлами
  нет; отказ одновременно удаления файла и восстановления схемы не маскируется
  обещанием полной транзакционности.
- Приложение рассчитано на один процесс и изменения данных через его команды.
