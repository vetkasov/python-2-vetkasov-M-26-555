# Выполнение по этапам

## 01. Инициализация — v2/01-package

Реально выполнен uv init; создан main.py, очищен __init__.py, настроены
имя дистрибутива и две точки входа. Три запуска выводят приветствие.
Импорт main не запускает программу.

## 02. Подготовка — v2/02-preparation

Добавлены prompt, welcome(), цикл help/exit, dev-зависимость Ruff и Makefile.
Проверены регистр команд, help/exit, три запуска, импорт без вывода и отсутствие
ANSI. Ruff и сборка проходят. Dry-run завершился с кодом 0 без передачи
токенов/паролей. Wheel установлен через uv tool и запущен вне проекта.
Обе записи подготовки опубликованы и встроены в README.

Закрытые тесты Практикума не предоставлены и не запускались.

## 03. Таблицы — v2/03-tables

Реализованы схемы, создание, список, удаление и JSON-хранилище.
Проверены точные сообщения создания/повторного создания/удаления/отсутствия,
порядок ID, регистр имён, неверные типы и повторные столбцы, перезапуск,
физическое удаление, повторное создание без старых данных и ошибка сохранения
схемы без удаления записей. Две группы локальных проверок прошли.
Отдельная запись установки и работы опубликована и встроена в README.
