## Текущий шаг: 01 — инициализация пакета

Разработка начата с пустой рабочей папки командой:

```bash
uv init --package --name primitive_db --python 3.12 .
```

Затем создан main.py, очищен __init__.py и настроены точки входа.
Имя дистрибутива — project-2-vetkasov-m-26-555, Python-пакет — primitive_db.
Настройка module-name нужна сборщику из-за различия этих имён.

## Установка и запуск

```bash
uv sync
uv run python -m primitive_db.main
uv run database
uv run project
```

Каждый запуск выводит одну строку и завершает работу:

```text
DB project is running!
```

Python: 3.12 и выше. Зависимостей приложения на этом шаге нет.
При импорте primitive_db.main функция main() автоматически не вызывается.
__init__.py пустой; исходники находятся в src/primitive_db.
